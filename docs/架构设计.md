# 同花顺免费开源AI插件FQGate V2 架构

## 职责边界

FQGate 是独立版本的本机服务，负责行情、账户、交易、OpenAPI、MCP 工具生成和 STDIO 到 Streamable HTTP 的传输桥。公开 Agent 仓库只维护 AI 客户端入口、公共配置发现、技能说明、SDK 和配套版本范围；FQGate 主程序、下载清单和文件校验值统一由 [FQGate 官方发行仓库](https://github.com/fqgate/FQGate-releases)提供。

```text
AI-plugins/{claude-code,workbuddy,zcode,openclaw,deepseek-harness,qianwen}
                                  │
                                  │ node scripts/launch-fqgate-mcp.mjs
                                  ▼
                       fqgate --mcp-stdio
                                  │
                                  ▼
                    http://127.0.0.1:17281/mcp

AI-plugins/{codex,doubao} ─── 本机 HTTP 连接器 ────┘
```

启动器不解析或转写 MCP 消息。真正的 STDIO 桥由 FQGate 可执行文件执行，因此工具、资源、分页、结构化结果和协议版本只有一个实现来源。

## 共享配置

配置器只保存以下非凭据信息：FQGate 可执行文件绝对路径、回环 MCP 地址、检测到的版本和更新时间。

- Windows：`%LOCALAPPDATA%\fqgate\agent-plugin.json`
- macOS：`~/Library/Application Support/fqgate/agent-plugin.json`

配置器与启动器只接受 `127.0.0.1`、`localhost` 或 `::1` 的 HTTP `/mcp`。自定义端口可以保存，但不允许凭据、查询参数、片段、局域网地址或公网地址。

一个电脑上的所有 AI 客户端复用同一配置和同一个 FQGate 桌面服务。卸载某个客户端入口时，不删除共享配置或 FQGate 程序。

## 技能分层

- “同花顺免费实时数据代理”：FQGate 安装连接、行情登录、证券搜索、行情、K 线、Level-2、资讯、板块、排行和期权。
- “同花顺实盘交易代理”：交易登录、账户、资产、持仓、各类记录查询，以及真实资金操作的逐笔核对、确认和防重规则。

各宿主只维护一份 `ADAPTER.md`。发行构建把适配说明合并到两个公共代理技能中，避免复制接口字段或维护八套业务规则。

## 实时接口

MCP 目录只包含可映射为单次 HTTP 请求的工具。FQGate WebSocket `/v1/market/stream` 与短线精灵 SSE `/v1/market/watch/short-line-events` 保持原生接口，不伪装成一次性工具；需要持续消费时由 SDK 或专用客户端读取 `fqgate://openapi` 后建立流连接。

## 交易安全

FQGate 默认不暴露真实写工具。只有显式使用 `--enable-mcp-trading-writes` 启动时才会加入工具目录。Agent 必须在每笔操作前展示关键参数并取得明确确认，使用唯一 `clientRequestId`；超时、断连或状态未知时先查询正式记录，禁止自动重试。
