# 开源范围

## AGPL-3.0-only 范围

- `.claude-plugin/**`
- `AI-plugins/**`
- `installer/**`
- `skills/**`
- `sdk/**`
- `scripts/**` 与根目录公开构建入口
- `fqgate/**` 中的兼容和发行元数据
- 本仓库公开文档

以上源码的修改版和衍生版在传播或通过网络向用户提供服务时，应按 AGPL-3.0 提供对应源码，并保留 `ADDITIONAL_TERMS.md` 指定的合理署名。

## 不在本许可证范围

- FQGate 私有源码、调试符号、研究材料、密钥和本机数据；
- 通过 Release 单独分发的 FQGate 编译包；
- 第三方组件及其许可证文本；
- 赞助者头像、收款码和交流群二维码等个人图片。

FQGate 编译包适用其随包许可，版本、下载地址和校验值由 [FQGate 官方发行仓库](https://github.com/fqgate/FQGate-releases)提供；本仓库只记录兼容关系。
