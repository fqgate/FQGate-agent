# FQGate 条件选股

把“找出符合条件的股票”作为可复核的两阶段流程：先筛选，再核验当前盘面。不得把筛选结果直接描述为投资建议。

## 执行流程

1. 提取用户明确给出的市场、行业、财务、题材、技术、时间和排序条件。没有必要时不擅自添加过滤条件。
2. 条件存在关键歧义时先澄清；条件完整时调用 `fqgate_selection_natural_language`。
3. 保留问财返回的证券代码、名称、命中字段和排序依据，不从展示名称猜证券代码。
4. 对最终要介绍或比较的沪深京候选调用 `fqgate_quote_mainland`；需要趋势判断时再调用 `fqgate_bar_series`。
5. 如果候选很多，只核验用户要求的数量或排名靠前的合理子集，并明确说明截断规则。

## 输出要求

- 先列出原始筛选条件与结果时间，再给候选及其命中理由。
- 分开标注“问财筛选字段”“FQGate 实时行情”和“AI 解释”。
- 指明缺失字段、停牌、行情时间差或复核失败的候选，不用估算补齐。
- 说明结果是条件筛选，不代表适合用户，也不承诺收益。
