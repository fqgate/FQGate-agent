# 同花顺免费实时数据代理 (FQGate)

本技能提供可验证的市场实时数据。涉及具体标的的判断必须先取得当前盘面；其他 FQGate 专项技能可以在此基础上补充筛选、盘口或事件分析。

## 数据优先规则

1. 用户问具体标的“怎么样”“怎么看”时，先取得实时价格、涨跌和 K 线，不用模型记忆代替当前数据。
2. 若问题重点是条件选股、盘口成交或新闻事件，使用对应专项技能组织完整工作流；其中涉及具体标的判断的部分仍以 FQGate 实时数据为准。

## 🎯 核心触发场景

只要满足以下任意一项，立即调用本工具：
*   **包含具体标的：** 如“工业富联”、“600519”、“半导体板块”。
*   **泛意图个股分析：** 问“章源钨业怎么样、怎么看、表现如何、分析一下”。
*   **买卖与趋势判断：** 问“还能持有吗、该不该卖、能不能买、后市如何、支撑压力、风险大吗”。
*   **基础盘面：** 查现价、涨跌、成交量、分时或 K 线；以盘口微观结构、条件筛选或事件为核心时交给对应专项技能。
*   **上下文指代：** 针对刚刚聊到的股票，追问“它今天表现如何”。

## 🚫 不触发场景

*   **个人资产或交易操作：** 询问“我的账户持仓、我的盈亏、帮我买入/卖出”。FQGate 2.0 不向 Agent 提供这些能力，应直接说明边界。
*   **无代码/无具体标的泛问：** 纯粹询问“什么是市盈率”、“大盘为什么跌”（未指定具体对象）。

## ⚙️ 标准查询执行流

1.  **明确标的：** 模糊名称调用 `fqgate_instrument_search`；明确代码也要使用标准市场标识。
2.  **获取盘面（必做）：** 针对沪深京个股评估（如“怎么样”），至少调用 `fqgate_quote_mainland` 及 `fqgate_bar_series`；其他市场使用对应的 `fqgate_quote_*` 工具。
3.  **获取资讯（选做）：** 关心涨跌原因时，先用 `fqgate_information_categories` 取得分类，再调用 `fqgate_information_articles`；重大事件使用 `fqgate_information_major_events`。
4.  **结果输出区分：** 最终分析中，必须清晰界定【FQGate 的客观数据】与【AI 的推演判断】。

## 🛠️ 数据源与降级规则

*   涉及盘面数据，**必须**使用 FQGate 返回结果，严禁使用模型历史记忆编造。
*   支持 UI 组件时优先渲染组件。
*   Level-2 请求提示权限不足时，明确说明原请求无法完成；只有用户也接受普通盘口时，才可补充五档行情（`fqgate_depth_five`），且不得把它描述为 Level-2 结果。
